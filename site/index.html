如何激活

  1. 安装卖家提供的付费包 Edge 扩展（不要用内部试用包当授权版）。
  2. 打开扩展弹窗 →「授权激活」。
  3. 粘贴收到的 JSON 或 Base64 令牌 → 确认激活。
  4. 令牌与本机 installId 绑定；换机需重新联系卖家处理。

激活为离线校验；生产 HTTPS 在线复验上线后可并存，不影响本流程。
