# hotjob 同壳下一租户：登录后一键试填准备清单（草稿）

适用候选：Celebright / 国盛等。**仅供准备与验收，目标租户尚待实测，不构成已支持声明。**

### 前置

- 已知基线：南粤 CMS_BASIC live PASS，`personalVerified=8`；剩余 skip 需 `customScopedAnswers`。Shell class 11/11、脚本覆盖壳键，仅作已有证据，不代替新租户验收。
- 从 `run-hotjob-tenant.cmd` 核对并记录：**目标租户对应的实际键、域名、壳映射及调用方式**。本材料未提供键名，保留【待核对原值】，不编造参数。
- 准备目标租户账号及试填资料；先确认页面是否自动保存。存在自动保存或持久化行为不明时，不进入试填。

### 步骤

1. **人工登录并停页**：停在目标租户的简历编辑表单，表单已加载、无登录或验证码遮挡；记录租户名、域名、页面路径。列表页、预览页、保存确认页不作为试填起点。
2. **核对脚本键**：确认选中键与当前租户、域名、壳一致；映射不明即暂停，不借用南粤键继续。
3. **记录试填前状态**：记录字段初值、预计可填项及 skip；开启覆盖试填全过程的请求观察。
4. **执行一次现有“一键试填”**：仅观察字段回填、匹配及 skip，不触发保存、提交或投递。
5. **收集结果**：分别记录本租户的成功项、skip、误填、报错，以及 Never Save 证据；缺口列入该租户的 `customScopedAnswers` 待补项。

### 判据

- **停页合格**：登录有效、租户身份明确、目标表单可编辑，脚本键映射一致。
- **试填结果可核对**：字段值与预期逐项对应；`personalVerified` 按本租户实测记录，不沿用南粤的 8。
- **Never Save 合格**：全过程无保存、提交、投递动作，也无相应持久化请求；仅“未点击保存”不足以判 PASS。
- **证据隔离**：使用独立租户记录与验收结论；南粤 PASS、壳分类通过、脚本键覆盖分别引用，不推导新租户 PASS。证据不足记“待验”。

### 禁止项

- 不放宽引擎 scope，不以通用兜底强填 skip。
- 不复用南粤专属答案、租户标识或验收结果。
- 不点击保存、提交、投递，或可能触发持久化的下一步。
- 不修改仓库、不提供完整插件代码、不制定对外口径、不宣称新增支持；可卖范围仍仅 CMS+GTH。
